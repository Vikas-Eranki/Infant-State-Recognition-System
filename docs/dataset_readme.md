**Total Files:** 1,126 audio recordings

### Overview

The Baby Cry Sense Dataset contains categorised audio recordings of infant cries,
aimed at supporting AI applications that recognise the emotional or physiological
needs of babies through sound. The dataset is derived from the
[Donate-a-Cry corpus](https://github.com/gveres/donateacry-corpus) (Veres, 2015)
and is intended for training machine learning and deep learning models to classify
infant cry types in real-time assistive applications.

| tired | 142 | 12.6% | Infants crying due to tiredness or need for sleep |

### Critical EDA Finding — Sampling Rate Artifact

The two sample rate populations are **not uniformly distributed across classes**.
`hungry` is 100% at 8,000 Hz while `scared` is 81.8% at 44,100 Hz. A model
trained without resampling would learn to distinguish recording quality rather
than actual cry patterns. This artifact is unreported in any prior publication
on this corpus and was discovered during EDA (see `notebooks/01_EDA.ipynb`,
Section 7).

## 2. Processed Dataset

**Name:** BabyCryDataset\_processed
**Source:** [Kaggle — noxpie](https://www.kaggle.com/datasets/noxpie/baby-cry-preprocessed-dataset)
**Generated by:** `notebooks/02_DataPreprocessing.ipynb`
**Total Files:** 1,334 audio files + 3 metadata files
**Total Size:** ~451 MB

### What the Preprocessing Pipeline Does

The raw dataset is transformed through the following steps, each justified by
EDA findings:

| Step | Action | Justification |
|---|---|---|
| Format conversion | `.3gp`, `.ogg`, `.mp3` → `.wav` | Standardise for librosa/soundfile |
| Resampling | All files → 22,050 Hz | Neutral between 8 kHz and 44.1 kHz populations; preserves up to 11,025 Hz |
| Duration normalisation | Pad (zeros) or trim to 7.0 s | 95th percentile = 7.02 s; retains 94.8% of files intact |
| Amplitude normalisation | Peak-normalise to 1.0 | Removes microphone gain variability |
| Quality check | Remove silent files (peak < 0.01) | 1 file removed from `lonely` class |
| Augmentation | Minority classes → 130 samples minimum | Addresses 15.9:1 imbalance |

### Augmentation Details

Augmentation was applied only to classes below 130 samples:

| Class | Original | Augmented Added | Final | Synthetic % |
|---|---|---|---|---|
| burping | 124 | 6 | 130 | 4.6% |
| lonely | 24 | 106 | 130 | 81.5% |
| scared | 33 | 97 | 130 | 74.6% |

**Techniques used:** time stretching (rate 0.8–1.2), pitch shifting (±2 semitones),
Gaussian noise injection, and time shifting with wrapping.

**Important limitation:** the high synthetic ratio for `lonely` (81.5%) and
`scared` (74.6%) means per-class F1 scores for these classes should be interpreted
with caution — high scores may reflect augmentation pattern memorisation rather
than genuine acoustic generalisation.

### Metadata Files

**`clean_manifest.csv`** — one row per audio file, 7 columns:

| Column | Description |
|---|---|
| `file_path` | Absolute path at preprocessing time |
| `file_name` | Filename (e.g. `cry_001.wav`, `aug_lonely_001.wav`) |
| `category` | Class label string |
| `sample_rate` | Always 22,050 Hz post-processing |
| `duration_sec` | Always 7.0 s post-processing |
| `num_samples` | Always 154,350 (7.0 × 22,050) |
| `is_augmented` | `True` for synthetic files, `False` for originals |

**`augmentation_log.csv`** — records every augmented file with its source original,
augmentation technique applied, and class.

**`preprocessing_params.json`** — all hyperparameters used during preprocessing
for full reproducibility:

```json
{
  "target_sr": 22050,
  "target_duration": 7.0,
  "target_samples": 154350,
  "amplitude_threshold": 0.01,
  "augment_minority": true,
  "min_samples_per_class": 130
}
```

### How to Use This Dataset

This processed dataset is the direct input to `notebooks/03_feature_engineering.ipynb`.
Audio files are loaded, converted to Log-Mel Spectrograms (128 × 302), and saved
as `X.npy` and `y.npy` for model training.

```python
# On Kaggle
KAGGLE_INPUT  = "/kaggle/input/datasets/noxpie/baby-cry-preprocessed-dataset"
DATASET_ROOT  = os.path.join(KAGGLE_INPUT, "BabyCryDataset_processed")
MANIFEST_PATH = os.path.join(DATASET_ROOT, "clean_manifest.csv")
AUDIO_DIR     = os.path.join(DATASET_ROOT, "audio_clean")
```

**Important:** augmented files (`is_augmented == True`) must never appear in the
test set. The feature engineering and baseline notebooks enforce this via an
augmentation-aware stratified split (see `notebooks/04_baseline_ml.ipynb`,
Section 3).
